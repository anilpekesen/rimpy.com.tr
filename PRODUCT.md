# Product

## Register

product

## Users

Mimar CMS is used by agency staff and non-technical customer editors who maintain corporate websites. They work in an authenticated control panel to publish pages and recurring content, manage navigation and media, and assemble layouts without editing code.

## Product Purpose

Provide one secure, reusable Laravel CMS core for multiple independently deployed customer websites. A successful installation gives each customer the content modules, multilingual publishing tools, media workflow, forms, navigation, SEO controls, and visual page builder needed for a typical corporate site while keeping executable plugin code out of the control panel.

## Brand Personality

Calm, familiar, dependable. The control panel should feel straightforward to occasional editors and efficient to experienced agency staff.

## Anti-references

Avoid WordPress-style plugin sprawl, hidden dependencies, decorative dashboard clutter, unfamiliar controls, and interfaces that require technical terminology for routine content work. Avoid copying a customer site's branding into the control panel.

## Design Principles

1. Use familiar editing patterns and plain Turkish labels so occasional users can complete tasks without training.
2. Keep one content model flexible enough for products, news, projects, references, offices, announcements, FAQs, and similar corporate content.
3. Make site-wide relationships explicit: menus link to records, reusable templates update consistently, and media comes from one library.
4. Preserve safe defaults and clear recovery paths through validation, revisions, activity records, and non-destructive states.
5. Keep the panel visually stable across customer installations while allowing each public website to have its own identity.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the control panel and generated public interfaces. All primary workflows must support keyboard operation, visible focus, adequate contrast, descriptive labels, reduced motion, meaningful alternative text, and status feedback that does not depend on color alone.
